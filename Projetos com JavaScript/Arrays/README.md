# Exemplo de Arrays

## O que este projeto faz
Este projeto mostra, de forma simples, como funciona um array em JavaScript: criar, acessar, alterar e adicionar valores.

## Arquivos desta pasta
- arrays.js

## Como abrir e testar
1. Abra o arquivo arrays.js em uma pagina HTML ou console JavaScript.
2. Execute o codigo e abra o console do navegador (F12).
3. Observe as operacoes de leitura e alteracao dos itens do array.

## O que voce aprende aqui
- O que e um array e como acessar por indice.
- Como adicionar novos elementos com push().
- Como consultar tamanho e ultimo elemento da lista.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
