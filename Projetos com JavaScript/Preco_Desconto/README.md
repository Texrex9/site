# Calculadora de Desconto

## O que este projeto faz
Este projeto calcula o valor do desconto e o preco final de um produto com base na porcentagem informada.

## Arquivos desta pasta
- precoDesconto.css
- precoDesconto.html
- precoDesconto_new.js

## Como abrir e testar
1. Abra o arquivo precoDesconto.html no navegador.
2. Digite o preco original e a porcentagem de desconto.
3. Clique em Calcular Desconto para ver o resultado.

## O que voce aprende aqui
- Validacao de entradas numericas.
- Calculo percentual em JavaScript.
- Apresentacao de resultado no HTML e em alertas.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
