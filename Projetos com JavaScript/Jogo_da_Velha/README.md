# Jogo da Velha

## O que este projeto faz
Este projeto implementa um jogo da velha para duas pessoas, com validacao de vitoria e reinicio da partida.

## Arquivos desta pasta
- jogoDaVelha.html
- jogoDaVelha.js

## Como abrir e testar
1. Abra o arquivo jogoDaVelha.html no navegador.
2. Jogador 1 usa X e jogador 2 usa O, alternando cliques nas celulas.
3. Quando alguem vencer, reinicie pelo botao Reiniciar Jogo.

## O que voce aprende aqui
- Controle de estado do jogo.
- Verificacao de combinacoes vencedoras.
- Eventos de clique em varios elementos.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
