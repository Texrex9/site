# Teste com Do-While

## O que este projeto faz
Este projeto usa o laco do-while com confirmacoes do usuario para percorrer uma lista de carros.

## Arquivos desta pasta
- testeDoWhile.html
- testeDoWhile.js

## Como abrir e testar
1. Abra o arquivo testeDoWhile.html no navegador.
2. Responda aos dialogs de confirmacao para continuar ou parar.
3. Observe na pagina quais itens foram processados.

## O que voce aprende aqui
- Diferenca entre while e do-while.
- Fluxo de repeticao com interacao do usuario.
- Registro visual do processamento na pagina.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
