# Verificacao de Nota

## O que este projeto faz
Este projeto informa se o aluno foi aprovado ou reprovado com base na nota digitada.

## Arquivos desta pasta
- javaScript.css
- javaScript.html
- javaScript.js

## Como abrir e testar
1. Abra o arquivo javaScript.html no navegador.
2. Digite uma nota entre 0 e 10.
3. Clique no botao para verificar o resultado.

## O que voce aprende aqui
- Comparacao de valores com if/else.
- Validacao de faixa numerica.
- Atualizacao do resultado na tela com feedback visual.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
