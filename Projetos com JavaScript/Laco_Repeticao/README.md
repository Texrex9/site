# Exemplos de Lacos de Repeticao

## O que este projeto faz
Este projeto mostra diferentes lacos (while, do-while, for e for-of) percorrendo dados na pagina.

## Arquivos desta pasta
- lacoRepeticao.html
- lacoRepeticao.js

## Como abrir e testar
1. Abra o arquivo lacoRepeticao.html no navegador.
2. Observe as secoes criadas automaticamente com os resultados de cada laco.
3. Compare o mesmo resultado usando estruturas diferentes.

## O que voce aprende aqui
- Como funcionam while, do-while, for e for-of.
- Quando usar cada tipo de repeticao.
- Como montar conteudo dinamico com loops.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
