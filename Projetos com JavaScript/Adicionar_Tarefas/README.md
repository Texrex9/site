# Lista de Tarefas

## O que este projeto faz
Este projeto permite criar uma lista de tarefas, adicionar novos itens, excluir itens e finalizar a lista para visualizacao.

## Arquivos desta pasta
- tarefasToDoList.css
- tarefasToDoList.html
- tarefasToDoList.js

## Como abrir e testar
1. Abra o arquivo tarefasToDoList.html no navegador.
2. Digite uma tarefa no campo e clique em Adicionar.
3. Use Excluir para remover um item da lista.
4. Clique em Finalizar Lista e, se quiser, em Reabrir Lista para continuar editando.

## O que voce aprende aqui
- Como capturar elementos HTML com JavaScript.
- Como responder a cliques de botoes com eventos.
- Como criar e remover itens de uma lista na tela.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
