# Repeticao com While

## O que este projeto faz
Este projeto apresenta exemplos simples de repeticao com while para listar itens de um array na pagina.

## Arquivos desta pasta
- repeticao.html
- repeticao.js

## Como abrir e testar
1. Abra o arquivo repeticao.html no navegador.
2. Veja as secoes sendo montadas automaticamente com os dados da lista.
3. Compare as variacoes do while usadas no codigo.

## O que voce aprende aqui
- Estrutura basica do while.
- Controle de contador em repeticao.
- Geracao de HTML dinamico em loop.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
