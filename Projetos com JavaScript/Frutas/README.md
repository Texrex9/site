# Lista de Frutas com Array

## O que este projeto faz
Este projeto demonstra operacoes com uma lista de frutas usando array em JavaScript.

## Arquivos desta pasta
- frutas.html
- frutas.js

## Como abrir e testar
1. Abra o arquivo frutas.html no navegador.
2. Abra o console (F12) para ver os resultados.
3. Acompanhe criacao, alteracao e adicao de frutas no array.

## O que voce aprende aqui
- Manipulacao basica de arrays.
- Uso de indice para ler e alterar valores.
- Como exibir informacoes no console.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
