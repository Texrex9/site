# Validacao de Formulario

## O que este projeto faz
Este projeto valida campos de formulario antes do envio para evitar dados incompletos ou invalidos.

## Arquivos desta pasta
- validarForm.html
- validarForm.js

## Como abrir e testar
1. Abra o arquivo validarForm.html no navegador.
2. Preencha nome, telefone, email, senha e mensagem.
3. Clique em Enviar e corrija os avisos se aparecer algum erro.

## O que voce aprende aqui
- Validacao de formulario no lado do cliente.
- Uso de expressoes regulares para telefone e email.
- Bloqueio de envio quando os dados nao atendem as regras.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
