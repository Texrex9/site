# Troca de Cores por Clique

## O que este projeto faz
Este projeto muda a cor de blocos na tela quando voce clica em botoes e depois restaura o estado inicial.

## Arquivos desta pasta
- click.html
- click.js

## Como abrir e testar
1. Abra o arquivo click.html no navegador.
2. Clique em Troca de cor para pintar as divs.
3. Clique em Restaurar cor padrao para voltar ao visual original.

## O que voce aprende aqui
- Como alterar estilo CSS via JavaScript.
- Como associar funcoes a botoes.
- Como restaurar estado visual de elementos.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
