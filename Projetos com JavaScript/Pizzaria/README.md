# Pedido de Pizza

## O que este projeto faz
Este projeto simula um pedido de pizza com sabor, tamanho, adicionais e exibicao do pedido final.

## Arquivos desta pasta
- pizzaria.css
- pizzaria.html
- pizzaria.js

## Como abrir e testar
1. Abra o arquivo pizzaria.html no navegador.
2. Escolha sabor e tamanho da pizza.
3. Selecione adicionais, se quiser, e clique em Fazer Pedido.
4. Use Mostrar Pedido para revisar e Novo Pedido para limpar tudo.

## O que voce aprende aqui
- Leitura de selects simples e multiplos.
- Validacao de campos obrigatorios.
- Montagem de resumo de pedido para o usuario.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
