# Saudacao por Horario

## O que este projeto faz
Este projeto mostra uma mensagem de saudacao personalizada com base no nome e no horario informado.

## Arquivos desta pasta
- funcoes.html
- funcoes.js

## Como abrir e testar
1. Abra o arquivo funcoes.html no navegador.
2. Digite seu nome e escolha o horario.
3. Clique no botao para gerar a saudacao.

## O que voce aprende aqui
- Como criar e chamar funcoes.
- Como usar if/else para regras de negocio.
- Como atualizar texto na pagina com JavaScript.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
