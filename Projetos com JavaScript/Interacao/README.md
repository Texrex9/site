# Interacao com Botoes e Teclado

## O que este projeto faz
Este projeto permite mudar a cor de fundo da pagina e identificar teclas pressionadas pelo usuario.

## Arquivos desta pasta
- interacao.html
- interacao.js

## Como abrir e testar
1. Abra o arquivo interacao.html no navegador.
2. Clique nos botoes de cor para alterar o fundo.
3. Use o campo de texto e pressione teclas para ver a interacao.

## O que voce aprende aqui
- Eventos de clique e teclado.
- Alteracao dinamica de estilo da pagina.
- Leitura de dados do evento de teclado.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
