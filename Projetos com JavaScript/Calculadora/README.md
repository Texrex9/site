# Calculadora Basica

## O que este projeto faz
Este projeto faz contas simples com dois numeros: soma, subtracao, multiplicacao e divisao.

## Arquivos desta pasta
- calculadora.html
- calculadora.js

## Como abrir e testar
1. Abra o arquivo calculadora.html no navegador.
2. Digite o primeiro numero e o segundo numero.
3. Informe o operador (+, -, * ou /).
4. Clique no botao de calcular para ver o resultado.

## O que voce aprende aqui
- Leitura de dados digitados em inputs.
- Condicoes para decidir qual operacao fazer.
- Exibicao de resultado para o usuario.

## Observacao
- Nao precisa instalar nada.
- Se houver arquivo HTML na pasta, abra-o no navegador.
- Se houver apenas arquivo JS, execute em uma pagina de teste ou no console do navegador.
