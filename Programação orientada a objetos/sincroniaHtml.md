# sincronia.html — Página de teste assíncrono

## Descrição

Página HTML utilizada para executar e testar o comportamento assíncrono do arquivo `sincronia.js` no navegador.

## Como usar

1. Abra o arquivo `sincronia.html` em um navegador.
2. Abra o **DevTools** (F12) e acesse a aba **Console**.
3. Observe as mensagens exibidas, demonstrando o comportamento não-bloqueante das Promises.

## Arquivo relacionado

- [sincronia.js](sincronia.js) — contém o código assíncrono carregado por esta página.
