# Flex Box

Este exemplo mostra como distribuir caixas em linha usando Flexbox.

## O que esta pasta contém

- `flexbox.html`: cria uma área principal com três caixas numeradas.
- `flexbox.css`: define as cores, o tamanho das caixas e a forma como elas ocupam o espaço.

## O que a página faz

- Coloca três blocos lado a lado.
- Dá uma cor diferente para cada bloco.
- Faz os blocos crescerem em tamanhos diferentes dentro da mesma linha.

## O que uma pessoa iniciante pode observar

- `display: flex` coloca os elementos em uma linha por padrão.
- `flex-direction: row` confirma que os itens devem ficar na horizontal.
- `flex-grow` controla quanto espaço cada caixa ocupa.
- Neste exemplo, a caixa 2 cresce mais do que as caixas 1 e 3.

## Como visualizar

Abra o arquivo `flexbox.html` no navegador.

## Resumo rápido

Este exemplo ajuda a entender como o Flexbox distribui o espaço disponível entre vários elementos.
