# Exercicio Aula

Este exemplo mostra um layout organizado em grade, parecido com a estrutura de uma página de site.

## O que esta pasta contém

- `index.html`: cria os blocos visuais da página, como cabeçalho, menu, colunas laterais, conteúdo principal e rodapé.
- `style.css`: define o visual desses blocos e posiciona cada um dentro de uma grade.

## O que a página faz

- Centraliza um quadro branco no meio da tela.
- Divide esse quadro em áreas bem definidas.
- Usa cores e espaçamentos para destacar cada parte do layout.

## O que uma pessoa iniciante pode observar

- `display: grid` é usado para montar a página em linhas e colunas.
- `grid-template-columns` define a largura das colunas.
- `grid-template-rows` define a altura das linhas.
- Cada classe, como `.header` ou `.content`, indica em qual parte da grade o elemento vai aparecer.

## Como visualizar

Abra o arquivo `index.html` no navegador.

## Resumo rápido

Este exemplo é útil para entender como montar a base visual de um site antes de adicionar textos, imagens ou funcionalidades.
