# Cores e Fontes

Este exemplo mostra uma página simples de apresentação pessoal feita com HTML e CSS.

## O que esta pasta contém

- `coresFontes.html`: monta a estrutura da página, com cabeçalho, três blocos de conteúdo e rodapé.
- `coresFontes.css`: define as cores, a fonte, o espaçamento e a organização visual dos blocos.

## O que a página faz

- Exibe um título no topo.
- Mostra três seções centrais com textos de exemplo.
- Mantém um rodapé fixo na parte de baixo da tela.

## O que uma pessoa iniciante pode observar

- O HTML serve para organizar o conteúdo.
- O CSS serve para mudar a aparência.
- A propriedade `display: grid` no arquivo CSS organiza as seções automaticamente em colunas, conforme o espaço da tela.
- As cores de fundo e de texto ajudam a separar cada parte da página.

## Como visualizar

Abra o arquivo `coresFontes.html` no navegador.

## Resumo rápido

Se alguém quiser alterar o texto, deve mexer no HTML.
Se alguém quiser mudar cores, tamanho, fonte ou posição dos elementos, deve mexer no CSS.
