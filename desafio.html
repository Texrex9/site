Desafio

Crie uma página HTML seguindo as boas práticas de estruturação, semântica e acessibilidade. A página deve conter um cabeçalho, um menu de navegação, uma seção principal com conteúdo relevante, uma barra lateral com informações adicionais e um rodapé. Certifique-se de usar as tags HTML apropriadas para cada parte da página e de incluir atributos de acessibilidade quando necessário.
